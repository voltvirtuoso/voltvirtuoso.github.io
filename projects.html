01

Intelligent Multi-Source Home Automation System (a.k.a. Smart Home System with ESP32)

An ESP32 controller that manages WAPDA grid, solar and backup generator power with automatic failover. It measures load with current transformers, reads temperature and humidity with a DHT22, shifts load to solar first, raises generator-fault alerts, and reports to Firebase for an MIT App Inventor app that controls four or more appliances.

ESP32FirebaseCT monitoringMIT App Inventor

Solar → grid → generator priority, with a generator-start response when two primary sources fail.

02

Smart Cart ML Module (Collaborative)

A shopping-cart prototype built around a ResNet18 few-shot object detector with barcode fallback, a RAG chatbot, a Django web app and an Android companion app, documented in a full technical report. On a Raspberry Pi 5, the few-shot detector reached 88.4% accuracy and 9.2 FPS, outperforming a YOLO11 baseline on every measured metric.
