Intelligent Multi-Source Home Automation System (a.k.a. Smart Home System with ESP32)

ESP32-based home automation managing WAPDA grid, solar, and backup generator sources with automatic failover logic. 02

Smart Cart ML Module (Collaborative)

A working retail-cart prototype built around a ResNet18 few-shot object detector with barcode fallback, a RAG chatbot, a Django-based web app, and an Android companion app — documented in a full technical report. On a Raspberry Pi 5, the few-shot detector reached 88.4% accuracy and 9.2 FPS, outperforming a YOLO11 baseline on every measured metric.

Dual-Method Water Level Management

A two-PCB water-management system: a secondary board senses a supply tank by both conductive and ultrasonic methods, while a main board combines its own sensing with those readings to control the pump. On-board LEDs report level in five states without needing an app.
